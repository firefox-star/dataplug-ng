# DataPlug.ng

Nigeria's cheapest data bundle platform. Buy MTN, Airtel, Glo and 9Mobile data plans instantly.

## Tech Stack
- Next.js 16 (App Router)
- TypeScript
- Prisma + SQLite
- Tailwind CSS 4
- shadcn/ui
- Framer Motion

## Setup
```bash
npm install
npx prisma db push
npm run dev
```

## Environment
```
DATABASE_URL=file:./db/custom.db
```
